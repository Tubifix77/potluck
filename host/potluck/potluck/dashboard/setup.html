Make your cell

A cell is your boards working as one. Give it a short name, and a passphrase that locks its keys on this PC.

Write the passphrase down. It is kept nowhere: without it, nobody -- you included -- can add a board or change the cell's apps. Losing it means setting the cell up again.

Add boards to

The cell has 0 board(s). New boards get exactly what the others run: the same firmware, the same keys, the same apps.

You can always add more later.

Plug in the new boards

Plug each new board into this PC with a USB cable. Each one shows up below, and Potluck checks what it is.
