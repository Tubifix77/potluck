# History

How Potluck came to be, kept for the record. None of it is needed to use Potluck or build on it -- start with
[GETTING-STARTED.md](../GETTING-STARTED.md) instead -- and none of it is a source of facts: where these files and
the current documents disagree, the current ones are right.

| file | what it is |
|---|---|
| `dmuOS_Architecture_Vision_Document*.pdf` | The three vision documents Potluck grew from, written when the project was called dμOS. Mine them for intent, never for facts; several of their numbers are corrected in [ARCHITECTURE.md](../ARCHITECTURE.md), section 3.1. They keep their old names because they really were written about dμOS. |
| `duOS.png`, `duOS2.png` | Mood boards from the old name (the second has garbled AI-generated text). |
| [first-analysis.md](first-analysis.md) | The external review that motivated merging the vision documents into one architecture. |
| [second-analysis.md](second-analysis.md) | An adversarial re-read of the architecture; all twelve findings were resolved into ARCHITECTURE.md on 2026-08-01. |
| [M0-BRIEF.md](M0-BRIEF.md) | The work order for the first milestone, "two boards, one heartbeat". |
| [HARDWARE-FREE-PLAN.md](HARDWARE-FREE-PLAN.md) | The plan for what to build while the first boards were in the post; all of it done (2026-08-23). |
